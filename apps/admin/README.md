# @carebridge/admin

Admin Portal (blank shell) — Vite + React + TypeScript, Capacitor-wrapped (iOS + Android). Themed via `@carebridge/design-system` (`data-app="admin"`).

## Commands (run from the repo root)

- `pnpm --filter @carebridge/admin dev` — start the dev server
- `pnpm --filter @carebridge/admin build` — production build
- `pnpm --filter @carebridge/admin test` — run tests (Vitest + Testing Library)
- `pnpm --filter @carebridge/admin lint` — lint (uses the shared root ESLint config, see `eslint.config.js`)
